# Hao Li Portfolio

Personal portfolio with projects, experience, publications, and travel photographs.

## Edit

- Content: index.html
- Styles: personal.css
- Photo viewer: personal.js
- Images and CV: assets/

This is a static site with no build step.

## Deploy

GitHub Actions publishes this website to GitHub Pages when changes are pushed to main.
The repository's Pages source should be set to GitHub Actions.

The source photographs and portfolio content belong to their respective owners.
